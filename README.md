# Лабораторная работа № 6 по курсу «Автоматическая обработка текстов».

Исследование поведения языковой модели при ответах на вопросы по длинному вымышленному досье с разнесёнными фактами, временными зависимостями, правилами, исключениями, противоречиями и нерелевантной информацией.


## Состав команды и распределение ролей

| Участник | ФИО | Ответственность |

| 1 | Дедкова А. В. | досье, атомарные утверждения, вопросы и эталоны |
| 2 | Генне К. В. | BM25, p-adic организация и построение контекста |
| 3 | Маракулин А. А.| LLM, Streamlit-интерфейс, метрики и тестирование |


## Что сравнивается

Три режима подачи контекста одной и той же LLM с одним системным промптом:

- **A. Полный контекст** - всё досье в фиксированном порядке.
- **B. Плоский retrieval** - BM25 top-15 утверждений плоским списком.
- **C. p-adic контекст** - те же top-15, сгруппированные по p-adic ветвям (p=3).

Контроль: одинаковая модель, одинаковые параметры, одинаковый набор `claim_id` в B и C; меняется только упаковка контекста.

## Установка и запуск

Нужны Python 3.11+ и ключ DeepSeek для новых запросов. Просмотр сохранённого архива доступен без ключа.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest -q
.venv/bin/streamlit run app.py
```

Ключ укажите в локальном `.env` как `DEEPSEEK_API_KEY=...`, в окружении, в скрытом поле интерфейса или через `--ask-key`. `.env` исключён из Git; в результатах ключа нет.
