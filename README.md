# AI-детектив

Лабораторная работа № 6 по курсу «Автоматическая обработка текстов».

Исследование поведения языковой модели при ответах на вопросы по длинному вымышленному досье с разнесёнными фактами, временными зависимостями, правилами, исключениями, противоречиями и нерелевантной информацией.

## Что сравнивается

Три режима подачи контекста одной и той же LLM с одним системным промптом:

- **A. Полный контекст** — всё досье в фиксированном порядке.
- **B. Плоский retrieval** — BM25 top-15 утверждений плоским списком.
- **C. p-adic контекст** — те же top-15, сгруппированные по p-adic ветвям (p=3) и упорядоченные по времени внутри ветвей.

Контроль справедливости: одинаковая модель, одинаковые параметры, одинаковый набор `claim_id` в B и C; меняется только упаковка контекста.

## Данные

- 10 документов, 5335 слов.
- 37 атомарных утверждений со статусами `direct | reported | inferred | disputed`.
- 12 вопросов: по 2 каждого типа (прямой, multi-hop, временной, правило+исключение, противоречие, недостаточно данных).

## Стресс-тесты

1. Перестановка документов (`random_state=42`).
2. Удаление необходимой посылки.
3. Добавление несовместимого утверждения.

Один фактор за раз, ожидаемый новый статус фиксируется вручную.
