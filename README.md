# AI-детектив — лабораторная работа 6

Сравнение трёх способов передачи вымышленного досье одной LLM: A — полный контекст, B — BM25 top-15, C — те же утверждения в p-adic ветвях. Во всех режимах использованы одна модель, один системный промпт и одинаковые параметры.

## Утверждённые данные

`documents.jsonl` и `claims.jsonl` побайтно совпадают с `main` на коммите `a8c60d8fa11552defdd840753849bab8a6b3196a`. По отдельному согласованию в `questions.jsonl` добавлено только поле `question_type`, остальные поля сохранены. Все исходные 28 стресс-кейсов неизменны; добавлены восемь контрольных удалений C13. Новые утверждения, правки текстов и изменения исходных эталонов не внесены. Поле `question_type` не передаётся LLM; неизменность запросов проверена по сохранённым контекстам.

- 10 документов, 5029 слов в полях `text` при подсчёте по пробелам;
- 37 утверждений;
- 12 вопросов с исходными эталонами;
- 36 стресс-кейсов: 12 перестановок, 12 удалений и 12 добавлений противоречия. Удаления Q03–Q06 убирают необходимую посылку; восемь остальных — контрольные, ожидаемый статус не меняется.

A получает документы в фиксированном порядке и реестр утверждений. B выбирает до 15 утверждений BM25, C использует тот же набор ID, группируя по пути при `p=3` и упорядочивая события по времени. Перестановка использует seed 42. Удаление убирает утверждение и его дословный фрагмент. Добавление противоречия включает новый документ и утверждение. Исходные и изменённые составы, полный переданный контекст и сырые ответы сохраняются.

### Ограничение исходной версии

Дословная проверка обнаруживает четыре несовпадения `evidence` с текстами документов: **C28, C35, Q07_contradiction, Q12_contradiction**. Поэтому строгий загрузчик отклоняет эти данные. По запросу пользователя эксперимент проведён на неизменённой версии `main` с явным флагом `--allow-nonverbatim-evidence`. Этот флаг допускает только недословные цитаты; неизвестные ID, отсутствующие документы и неверные ссылки по-прежнему отклоняются. Все четыре предупреждения записаны в каждую строку результатов и в манифест. Требование лабы о дословном `evidence` для этой версии не выполнено; результаты следует читать с этой оговоркой.

Q08_contradiction также допускает разные трактовки приоритета регламента и рекомендательного разъяснения. Q11–Q12 добавляют конфликт вспомогательного факта и сохраняют `insufficient`. Эталоны оставлены ровно такими, как в `main`.

## Установка и запуск

Нужны Python 3.11+ и ключ DeepSeek для новых запросов. Просмотр сохранённого архива доступен без ключа.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest -q
.venv/bin/streamlit run app.py
```

Ключ укажите в локальном `.env` как `DEEPSEEK_API_KEY=...`, в окружении, в скрытом поле интерфейса или через `--ask-key`. `.env` исключён из Git; в результатах ключа нет.

Повторный прогон утверждённых данных с фиксацией известных несовпадений:

```bash
.venv/bin/python run_experiment.py --model deepseek-flash --allow-nonverbatim-evidence
```

Без этого флага строгая проверка остановится на C28. В интерфейсе предупреждения видны сразу; новые запросы разрешаются после выбора соответствующего флажка. Просмотр данных и сохранённых результатов работает без разрешения новых запросов.

`--baseline-only` выполняет 36 исходных запросов. При сбое API можно продолжить с тем же `--run-id` и теми же флагами; ранее полученные ответы, включая невалидные, повторно не запрашиваются. Новые локальные ответы пишутся в игнорируемый `results/runs.jsonl`.
