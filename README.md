# AI-детектив — лабораторная работа 6

Исследование ответов `deepseek-flash` на вопросы по вымышленному досье. Сравниваются полный контекст (A), BM25 top-15 (B) и те же 15 утверждений, организованные по p-adic ветвям (C). Во всех режимах применены один системный промпт и одинаковые параметры модели.

## Участники и данные

| Участник | Вклад |
|---|---|
| Дедкова А. В. | Досье, утверждения, вопросы и эталоны |
| Генне К. В. | BM25, p-adic организация контекста и стресс-кейсы |
| Маракулин А. А. | LLM, Streamlit, метрики, интеграция и тесты |

В `data/` находятся 10 документов (5 023 слова в полях `text` при подсчёте по пробелам), 38 атомарных утверждений, 12 вопросов (по два каждого из шести типов) и 36 стресс-кейсов: по 12 перестановок документов, удалений и добавлений противоречащего источника. Среди удалений четыре убирают необходимую посылку Q03–Q06, восемь контрольных удаляют C13 без ожидаемого изменения статуса. Каждый случай имеет эталон. `src/data_io.py` проверяет ID, ссылки и дословные фрагменты доказательств. Материалы в `CLOUD_DOCS/` приведены в соответствие с `data/`; закрытая истинная последовательность не передаётся модели. По сообщению пользователя 17 октября 2026 года команда согласовала текущие данные; запись без личных подписей находится в `data/gold_review.md`.

A передаёт полное досье и реестр утверждений. B отбирает не более 15 утверждений BM25. C использует те же ID и сортирует их внутри p-adic ветвей при `p=3`. Перестановка документов использует seed 42, удаление убирает утверждение и его дословный фрагмент, добавление противоречия создаёт новый документ и утверждение. В результатах сохраняются контекст, исходный и изменённый составы, ответ и метаданные запроса.

## Запуск

Нужны Python 3.11+ и действующий ключ DeepSeek для новых запросов. Для просмотра готового архива ключ не требуется.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pytest -q
.venv/bin/streamlit run app.py
```

Ключ укажите в локальном `.env` как `DEEPSEEK_API_KEY=...`, в окружении, в скрытом поле интерфейса или через `--ask-key`. `.env` исключён из Git; ключ не сохраняется в архиве. Новый эксперимент из командной строки:

```bash
.venv/bin/python run_experiment.py --model deepseek-flash
```

`--baseline-only` запускает 36 исходных запросов. При сбое API прогон продолжается по прежнему `--run-id`; уже записанные ответы повторно не запрашиваются. Невалидные ответы модели сохраняются с сырым JSON и считаются ошибками.

## Итоговый эксперимент

17 октября 2026 года проведён полный прогон **144/144** запросов (`run_id=lab6_20261017_current`, температура 0): 36 исходных ответов и 108 стрессовых. В итоговом архиве нет сбоев API; шесть ответов нарушили логическое правило непересечения `evidence_ids` и `counterevidence_ids` и оставлены невалидными. Архив содержит все переданные контексты и сырые ответы; манифест фиксирует SHA-256 данных и промпта:

- `results/deepseek_flash_current_20261017.jsonl.gz` — итоговые ответы;
- `results/deepseek_flash_current_20261017_manifest.json` — состав и контрольные суммы.

На 12 исходных вопросах точность статуса A/B/C с учётом невалидных ответов: **10/12, 10/12, 10/12 (83,3%)**. Полные метрики, знаменатели, стресс-тесты и разбор ошибок приведены в отчёте. Перестановка меняет контекст A, но оставляет контексты B/C прежними; изменение их ответов не следует объяснять изменением порядка документов.

В `results/` оставлены только итоговый архив и его манифест. Более ранние прогоны удалены из сдаваемой ветки. Новые локальные запуски пишутся в игнорируемый `results/runs.jsonl` и не меняют опубликованный архив.

## Сдача и воспроизводимость

`CLOUD_DOCS/Отчет.docx` — заполненный отчёт на 1259 слов; `CLOUD_DOCS/Отчет.pdf` — его копия для чтения. `CLOUD_DOCS/Отчет по исходному шаблону.docx` — вариант для сравнения, сохраняющий структуру и оформление командной заготовки; 1498 слов, внесённый текст выделен жёлтым. Остальные файлы `CLOUD_DOCS/` содержат досье, утверждения, вопросы, стресс-тесты, закрытую последовательность и проверку эталонов. `READINESS.md` отмечает проверенные требования и ограничения; `DEMO.md` содержит сценарий на семь минут. `AI_LOG.md` содержит 12 описанных эпизодов работы с ИИ: задачи, предложения, решения команды и способы проверки.

`src/` содержит поиск, построение контекста, стресс-модификации, вызов модели и оценку; `app.py` — интерактивный стенд; `tests/` — проверки. `generate_report.py` можно использовать для дополнительной технической PDF-сводки по архиву:

```bash
.venv/bin/python generate_report.py --results results/deepseek_flash_current_20261017.jsonl.gz --run-id lab6_20261017_current --output /tmp/lab6-metrics.pdf
```

Эта сводка не заменяет оформленный отчёт в `CLOUD_DOCS/`. Все персонажи и события вымышлены. Результаты относятся к одному корпусу, одной модели и одному прогону; уверенность модели не является измеренной вероятностью истины.
